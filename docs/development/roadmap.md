# Future Phases Roadmap (Preview)

## Phase 2: Symfony AI Integration & Matching Engine
- Local-first Symfony AI foundation with a resource- and quality-gated Ollama
  provider, plus explicitly consented cloud resume-fit analysis.
- Evidence-backed vacancy text parsing into editable, unsaved authoring drafts.
- Transparent salary, resume, and commute fit results rather than an opaque
  ranking score.
- Encrypted commute origins and Google Routes Essentials integration for the
  selected transport mode, including public transport.

## Phase 3: External API Extensions & Cloud Migration
- OpenGraph URL scraper to auto-fill vacancy titles and company logos from pasted URLs.
- Google OAuth / SSO integration.
- S3 cloud storage migration via Flysystem configuration switch.
